# Cybersecurity Tool: Password Strength & Keylogger Simulator

A comprehensive cybersecurity project focused on **Endpoint Security** and **User Authentication Auditing**. This tool contains two primary modules:
1. **Password Strength Evaluator:** Analyzes passwords against security benchmarks (length, case, special characters, numbers).
2. **Authorized Keylogger Simulator:** Demonstrates how endpoint keystroke logging works for auditing and security awareness training.

## Features
- Interactive CLI for testing password vulnerabilities.
- Safe logging of keystrokes to a local text file for analysis.
- Visual representation of password character distribution.

## Technologies Used
- **Language:** Python 3.x
- **Libraries:** `pynput` (Keystroke capturing), `requests` (API integration), `json`, `os`

## Setup and Run Instructions
1. Clone or download this project bundle.
2. Install dependencies using pip:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Python/Jupyter notebook script:
   ```bash
   python ShrutiAdangale_CyberSecurityProject.py
   ```
4. Follow the on-screen prompts to test passwords or initiate the keyboard auditor.
